# Documentation index

This repository holds the **legacy implementation** of the CS3011 Group 52 project. It is kept as a technical reference and a fallback while the team rebuilds the project under a human-led plan in [jayvaghela779/transit-demand-occupancy](https://github.com/jayvaghela779/transit-demand-occupancy). Status checked on 28 Oct 2026.
