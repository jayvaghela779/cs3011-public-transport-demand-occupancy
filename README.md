# gh-pages: public dashboard

This branch only publishes the GitHub Pages site for the CS3011 Group 52 dashboard:
https://jayvaghela779.github.io/cs3011-public-transport-demand-occupancy/

`index.html` is a copy of [`web/index.html`](https://github.com/jayvaghela779/cs3011-public-transport-demand-occupancy/blob/main/web/index.html) on `main`. It runs the app in the visitor's browser with stlite and loads the app code and the committed results from `main`, so results update with `main` and this branch only changes when `web/index.html` does. Edit `web/index.html` on `main` first, then copy it here.
